# ULTRON ⚡

An original Android AI voice assistant project.

## Current stage

- Native Android starter interface
- Speech input through Android's speech recognition activity
- Basic YouTube and WhatsApp launch commands

## Planned stages

- AI chat backend
- Text-to-speech responses
- Screenshot capture with user permission
- More Android app integrations
- User-controlled automation

## Build

The APK is built using GitHub Actions. Java, Gradle and Android SDK
are installed on the cloud runner, not on the user's phone.
